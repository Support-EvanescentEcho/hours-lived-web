# Hours Lived — Official Support Website

This repository contains the source code for the official support, privacy policy, terms of service, and documentation website for the **Hours Lived** mobile application.

## Repository Details

- **Host:** GitHub Pages (or preferred static hosting provider)
- **Tech Stack:** Vanilla HTML5, Vanilla CSS3 (custom Clannad styling), Vanilla JavaScript (asynchronous JSON localization).
- **Structure:**
  - `index.html` — The main structural page.
  - `assets/` — Graphics assets (official launcher icon, favicon).
  - `css/` — Custom typography and stylesheet bindings.
  - `js/` — Asynchronous theme switcher and language loader scripts.
  - `locales/` — Standalone JSON translation dictionaries for all 10 supported languages.
